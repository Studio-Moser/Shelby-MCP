## Confirmed contracts and implementation cautions

- **C1 — Temporal and historical behavior.** Both bounds are parsed before interval evaluation; `start <= now < end`, null-open and empty/reversed-inactive are explicit. RFC3339 offsets/nanosecond fractions and the one specified legacy UTC spelling are compared as instants without rewriting stored data. Rejecting malformed active bounds is distinct from historical readers, which retain raw access. New writes validate before mutation; `manage_edges_tool` must preserve the new safe date error instead of replacing every InvalidInput with an edge-type message. Both brief refutation paths need the same instant and predicate.
- **C2 — Raw connections and registration.** Registering at active query entry points covers callers that bypass Memory::open; a global OnceLock or initializer-only registration would not. Keep the planned tests for first/repeated registration while an unrelated cursor exists, independent/reopened connections and transactions. `pragma_function_list` can establish name/arity/flags, not Rust callback identity: document the function name as reserved and do not imply it authenticates a caller-owned connection against deliberate same-name callback replacement. No such hostile-connection authority is required for this slice. Reject incompatible registrations and never overwrite an in-use callback silently.
- **C3 — Page bounds and continuation.** Candidate-row pagination, last-scanned cursor and explicit continuation correctly permit empty active pages without claiming exhaustion. Preserve full edge metadata and fixed instant/type across pages; authorization remains the caller’s separate step. The page size bounds materialized candidate rows and Rust predicate evaluations, not necessarily SQLite scan/sort work or arbitrary historical metadata bytes. Adjust the plan’s “work per call” wording accordingly; no new index/schema framework is needed to promise a strict storage-engine work bound. A malformed candidate errors its page, while a malformed row beyond that page is not eagerly loaded.
